# MR18与MR25

## MR18：用户每日评分突增检测

一条每日记录对应平台、SOURCE用户、UTC日期。使用所有合法评分事件，按用户日目标精确聚合，再得到当天评分次数、负评次数和不同目标数。

按用户日期二次排序，历史从首次主动评分日起计算，无评分的历史日按0计入。至少7个历史日后，分别检查当天评分次数、负评次数是否达到max(5,历史日均次数+3×总体标准差)。当前日输出后再更新历史状态，任一条件满足就生成一条待核查记录。

四个Job分别完成目标计数、每日汇总、历史基线和候选用户摘要。windows保存全部评分日期，alerts保存待核查记录，users保存相关用户汇总。结果为Alpha 18,584条每日记录/137条待核查记录，OTC 25,659/262。

固定输出 /bitcoin/results/mr18，HBase表analytics_mr18。页面提供待核查记录最多的十名用户、每日评分量与待核查记录趋势以及中文明细。

## MR25：首次主动评分用户持续参与

仅根据SOURCE首次主动评分月划分用户群组；按用户月份汇总评分次数，每用户月对人数贡献1。通过带kind标记的用户Reduce Join连接首次月份和活动月份，最终按平台及群组月份聚合。

第k月为首次月之后精确的第k个自然月，参与率为该月活跃人数/群组人数，评分贡献保留全部合法事件。页面对比第1、3、6个月。默认群组至少30人，目标月份严格早于平台数据截止月才进入比较；第0月参与率必须为100%。完整定义见MR25_DEFINITION.md。

固定输出 /bitcoin/results/mr25，HBase表analytics_mr25。当前Alpha 3,286名主动评分用户、OTC 4,814名，共4,162条群组月份统计。
