# 当前六项任务的业务结论

数据为2010—2016年的Alpha 24,186条、OTC 35,592条历史评分。页面读取HBase当前发布批次，批次来源由接口提供。

| 任务 | 主要结果 | 业务解释 |
| --- | --- | --- |
| MR7 | Alpha用户243均分第一而正向Katz第320；用户1均分第314而两种Katz第一 | 直接评价高低和网络影响力是不同属性，应同时看分数、排名与评价数量 |
| MR18 | Alpha 137条待核查每日记录、96名用户；OTC 262条、152名用户 | 将评分事件压缩成可按用户和日期复核的清单；OTC 2013-08-15有10名用户触发负评突增，涉及260条负评 |
| MR22 | OTC的UTC18—23点评分占35.92%，UTC20点最多 | 历史评分更集中于UTC晚间时段 |
| MR25 | 同一批合格群组第1/3/6月参与率：Alpha 27.88%/11.50%/7.26%，OTC 25.40%/10.53%/6.79% | 长期持续评价由较少一部分用户贡献，可同时关注参与人数和评分次数 |
| MR26 | Alpha 248对、OTC 358对双向评分方向冲突；分差至少10的分别144和228对 | 从具体分歧关系开始复核，结合双方评价内容及时间理解差异 |
| MR27 | Alpha 665条、OTC 908条直接负边同时存在正向二跳支持 | 对正向传播结果应同时保留当事人的直接负评，并提供中介路径供解释 |

MR25比例用相同的合格群组人数加权：Alpha34组/2,991人，OTC43组/4,598人。第k月是精确月份，未在该月继续评分不等于离开平台。MR26统计分母仅为双向评价用户对。MR27的中介路径说明意见结构，结合直接评价使用。

当前Katz查询来自HBase已发布批次；API中的generations和hdfs_base给出来源，批次来源与源码运行参数应分别核对。
